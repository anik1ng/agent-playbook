# План перекройки: конвейер agent-playbook × cmux × agy (черновик-память)

Рабочий черновик Claude Fable 5. Фиксирует всё, что решено и проверено в сессии
2026-08-07…10, чтобы пережить сжатие контекста. Не спека — конспект для восстановления.

## Контекст в двух абзацах

Исходный документ проектировал конвейер вокруг agterm. В ходе ревью и тестов: (а) терминал
заменён на cmux (скриптуемый CLI/unix-socket, группы/воркспейсы, уведомления, iOS);
(б) центральный тезис «живая сессия = условие работоспособности песочницы» опровергнут и
заменён точной моделью песочницы agy; (в) найдены и проверены механизмы agy, которых
исходный документ не знал: hooks.json с deny, грамматика правил `command()/unsandboxed()`.

Ядро исходного документа устояло: worktree на задачу/ревью, разделение «думалка/станок»,
трёхступенчатая лестница спеки, уборка с гардом, `templates/` не трогаем (кроме дефектов).

## A. Переписать архитектурный документ (думалка даёт добро — пишу начисто)

1. **§2, карта cmux**: группа = проект, воркспейс = worktree (1 workspace = 1 ветка = 1 PR).
   Внутри воркспейса пейны/surface (агент + терминал через `--layout`). Думалка — воркспейс
   на главном чекауте. Ограничение: управлять cmux могут только процессы внутри cmux —
   весь конвейер живёт внутри него.
2. **§2, «ключевая идея» — заменить**: видимость и безопасность — РАЗНЫЕ свойства.
   Видимость даёт cmux-сессия; безопасность даёт `--sandbox` + hooks-политика. Интерактив
   остаётся осознанным выбором человека (запросы bypass = видимые решения), а не
   технической необходимостью.
3. **§3.5, модель песочницы agy (проверено экспериментами)**:
   - команды в песочнице бегут молча, без промптов; сеть детям отрублена;
   - файлы вне workspace — промпт с причиной; `~/.zshrc`, `~/.ssh` — hard deny;
   - bypass-одобрение = команда выполняется ВНЕ песочницы целиком;
   - правила: `command(x)` = молча в песочнице, `unsandboxed(x)` = молча вне (префиксные!);
     `unsandboxed(gh)` был дырой (покрывал merge) — удалён; допустимо узкое
     `unsandboxed(gh pr comment)`;
   - `.agents/hooks.json` + PreToolUse guard: deny для `git push`/`gh pr merge`/`gh pr close`
     РАБОТАЕТ (проверено: «Tool call denied by pre-tool hook»). Хуки бегут вне песочницы с
     полными правами; cwd хука = папка hooks.json (наш первый тест провалился из-за этого).
   - `ask_permission`/permissioned-github в локальном CLI НЕТ (managed-only).
4. **§3.6, запуск/суперсессия ревью**: ship вызывает `.agents/auto-review.sh <pr>`;
   рендер скрипта сам решает «как» (на этой машине — `cmux workspace create` с worktree
   ревьюера). Перед новым ревью — `close-workspace` старого (проверено: убивает дерево
   процессов). Worktree ревьюера: detached HEAD на sha head'а PR (одна ветка не может быть
   в двух worktree), персистентен на PR (fix-push = fetch + reset, install инкрементален).
5. **§3.3, передача брифа**: комментом в seed-issue (worktree не разделяют незакоммиченные
   файлы; `/do` и так читает комменты). Файл в docs/ коммитит spec-сессия в составе spec-PR.
   Плюс: человек читает спеку глазами до декомпозиции (дешёвая страховка за разъезд
   интервью/написания). Лестница — расширение brief-механизма AGENTS.md, не реверс правила;
   брейншторм-fallback в /do остаётся.
6. **§3.6, петля уведомлений**: guard-хук на `ask` дёргает `cmux notify` (работает только
   изнутри cmux — проверить при внедрении); вердикт — финальный шаг протокола зовёт notify.
   Бейджи «awaiting input» для agy не работают никогда (захардкожен список интеграций).
7. **§4, доказательная база — заменить целиком** результатами наших тестов (сеть/gh/psql,
   канарейка, kill-tree cmux, deny-hook, грамматика правил из бинарника, доки
   builtin/skills/agy-customizations). Пометить хвосты: notify изнутри cmux;
   `permissionOverrides` в хуке (авто-грант `gh pr comment` — вердикт без клика).
8. **Мои правки из ревью, вошедшие в план**: §5 пункты 6–7 понизить (AGENTS.md уже знает
   про несколько рабочих копий); добавить дефект «мутации не откатываются»; уборка — без
   `--force` у `git worktree remove`, гард «всё запушено» перед `branch -D`.

## C. Реализация (личный слой, вне playbook)

- launcher: worktree + провижининг (setup-worktree.mjs: deps, .env.local ФИЛЬТРОВАННЫЙ —
  только переменные гейта, тестовая БД) + `cmux workspace create`.
- guard.sh ревьюера: deny push/merge/close; ask+notify остальное сетевое.
- уборка: merged-гард → teardown БД → worktree remove (без --force) → branch -D (после
  проверки «всё на GitHub») → close-workspace последним.
- шелл-функция создания задачи (worktree+провижининг+workspace) — три шага, не два.

## D. Проверить при внедрении (хвосты)

1. `cmux notify` из-под sandbox-agy изнутри cmux-workspace.
2. `permissionOverrides` в PreToolUse (авто-грант узкого unsandboxed).
3. Поведение `cmux workspace create` при живом тёзке (имя «review #N»).
4. Цена холодного worktree (install + БД) на nsarchive.
5. Автообнаружение `.agents/skills/review/SKILL.md` агентом agy по `/review N` (доки
   говорят «да», прогнать один раз).
